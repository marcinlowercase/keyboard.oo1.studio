Privacy Policy

Application: the keyboard of oo1 studio • oo1 studio

The Core Principle: Zero Data Collection

the keyboard of oo1 studio is an offline developer keyboard created by oo1 studio. We believe your keystrokes, source code, server credentials, and personal communications belong exclusively to you.

We do not collect, monitor, log, store, or transmit any data you type using this keyboard.

Complete Offline Architecture

The keyboard does not require, request, or hold the network permission (android.permission.INTERNET). It is technically incapable of establishing an outbound network connection or transmitting your data over the internet.

  • No keystroke logging or telemetry.
  • No analytics or tracking SDKs.
  • No advertising networks or profiling.
  • No cloud synchronization of keyboard state.

Local Device Storage

All your preferences, custom key remappings, directional secondary bindings, and theme configurations are saved strictly on your local device via encrypted Android DataStore within the application's isolated sandbox.

When you choose to export your configuration JSON file, the file is saved exclusively to the storage directory you select via Android's native system file picker.

System Clipboard Interaction

The keyboard interacts with the Android system clipboard exclusively when you trigger copy, cut, or paste operations (such as Ctrl+C, Ctrl+X, or Ctrl+V). The keyboard does not retain clipboard contents or track your clipboard history.

Third-Party Services

The keyboard integrates zero third-party software development kits, crash analytics suites, or advertising modules.

Account Requirements

The application does not have user accounts, registration forms, or login portals. No identity verification or personally identifiable information is ever requested.
